Brain teaser

A Knobelaufgabe, the kind of small exercise you get on the first problem sheets of a computer science degree. Pen and paper are enough. Each part you solve sets one of the site's hidden bits.

Here is a function in Python. // divides and rounds down, % is the remainder.

def mystery(n):
    if n == 0:
        return 0
    return mystery(n // 2) + n % 2

  1. (a) What does mystery(2025) return?

    {% if solved.a %}

    Solved: {{ answers.a }}

    Each call adds n % 2, the last binary digit of n, then calls itself with n // 2, which drops that digit. So mystery counts the 1s in n written in binary. 2025 is 0b11111101001: eight 1s.

  2. (b) What is the smallest n for which mystery(n) returns 10?

    {% if solved.b %}

    Solved: {{ answers.b }}

    Every 1 needs a binary digit of its own, so ten 1s need at least ten digits. The only ten-digit binary number with ten 1s is 0b1111111111, which is 210 − 1 = 1023.

The function has a name: population count, or popcount. Most CPUs do it in a single instruction (POPCNT on x86), and it shows up wherever bits get counted, from Hamming distances to chess engines that store the board as bitmasks.
